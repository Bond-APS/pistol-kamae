4. 水平の線を引く（ライブラリで開いた記録から・全画面）

床と壁の境目など、本当は水平なものに線を合わせてください。両端の ● を指で動かします。線は長いほど正確です。

カメラの傾き：1.0°（右上がり）

保存すると、この記録の角度を 1.0° 分だけ補正して計算します。

キャンセルこの線で決める
線を消す（補正をやめる）

線の傾きが 10° を超えたとき

！ 傾きが大きすぎます（14.2°）

奥へ向かって延びる線（射台の前の縁など）は、水平でも斜めに写ります。カメラから見て左右に延びる線を選んでください。

写真は撃発の瞬間の静止画（全体）。端を動かしている間、左上の拡大鏡にその周りが大きく出る（指で隠れないよう、つまみは線の端より下にある）。まだ線が無い記録では「線を消す」は出ない。提案 柱やドア枠など鉛直なものに合わせても補正できるようにする案は、質問 5 を参照。
