## 4. 実装の要点（はまった点）

### video 要素は一度置いたら動かさない

WebKit（Safari、iPhone）では、video 要素を DOM の別の場所へ移し替えると、その後のシークが完了しなくなる
（骨格だけ動いて絵が固まる。iPhone 実機で開発者が発見）。プレイヤー（`VideoPlayer`）は `App.tsx` に 1 つだけ置き、
読込画面とマーク画面で共有している。並び順と表示・非表示は CSS（`.screens`、`.player-first`、`hidden`）で切り替える。
**③でライブラリ画面を足すときも、video 要素を動かす設計にしない。**

### 自動テストはフレーム番号だけでなく「絵」を見る

最初のテストは番号しか見ておらず、上の不具合を見逃した。`marktest.mjs` は動きのある動画（`motion.mp4`）で、
画面に出ている絵がフレームごとに変わることを確かめる。

### テスト動画は先頭フレームを 0 秒始まりで切り出す

`-vf "setpts=PTS-STARTPTS,fps=30" -bf 0` を付ける。0.033 秒始まりだと、WebKit は先頭付近で前の絵を残し、
Chrome は先頭フレームへ届かない。`static0.mp4`・`motion.mp4` は対策済み、旧 `static.mp4` は癖あり。
作り方は `marktest.mjs` の冒頭に書いてある。

### 自動テストが止まるとき

Playwright のウィンドウが他のウィンドウに隠れる、または Mac の画面が消灯・ロック中だと、描画の更新が止まり
時間切れになる（アプリの不具合ではない）。`marktest.mjs` は終了コード 2 を返すので再実行する。

### 開発サーバ

Claude は `preview_start` の `web` で起動する。**ターンやセッションをまたぐと止まっていることがある。**
自動テストの前と、開発者に実機確認を頼む前に、必ず `http://192.168.1.6:5173/`（IP は `ipconfig getifaddr en0`）が
200 を返すことを確かめる。

## 5. 自動テストの使い方

```
node apps/web/e2e/marktest.mjs webkit                                   据銃区間（static0.mp4）。①の実測と照合
VIDEO=apps/web/e2e/videos/motion.mp4 node apps/web/e2e/marktest.mjs webkit   動きあり。絵の検査を含む
node apps/web/e2e/autotest.mjs webkit video=/_test/friend-good-1.mov start=14 end=18   速度とノイズ
```

`webkit` を `chromium` に替えると Chrome。画面や解析に手を入れたら、コミット前に両方で回す。

### 作るもの

| # | 内容 |
|---|---|
| A | 保存：マーク画面に「ライブラリに保存」ボタン。撃発マークが付いているときだけ押せる |
| B | 保存する中身：関節の位置の時系列（共通ランドマーク形式 11 点）、fps・解像度、マーク、利き手、モデル名（`backendId`）、撃発フレームの静止画 1 枚、メタ情報（日付・射手名・点数・メモ・お気に入り） |
| C | ライブラリ画面：一覧（静止画・日付・射手名・点数・お気に入り）、射手名での絞り込み、お気に入りの切替（複数可）、メタ情報の編集、削除（確認付き） |
| D | ライブラリから開く：保存した 1 件を開くと、静止画＋骨格と撃発フレームの角度表が見られる |
| E | engine：保存形式の型（版番号付き）と単体テスト |

### 作らないもの

- 2 動画の比較、水平校正（④）。グラフ（⑤）。JSON 書き出し・読込（⑥）。初回画面の案内（⑦）
- 保存済みデータへの動画の再紐付け（動画本体は保存しない。開いたときは静止画で表示する）

### 決めてある設計

- 角度の時系列は保存せず、開くたびに関節の位置から計算する（二重に持つと食い違いの原因になる。⑥の書き出しには含める）
- 日付の初期値は動画ファイルの更新日時。後から編集できる
- 点数は小数、空欄可
- 保存には Dexie（IndexedDB を扱いやすくする部品、Apache 2.0）を導入する。CLAUDE.md 3 章で採用済みだが未インストール
- 保存・読込の処理はすべて端末内。外部送信なし

### 確認方法

- Claude が自動テスト（WebKit と Chrome）で、保存 → ページ再読込 → 一覧に残る、絞り込み、お気に入り、編集、削除を確かめる
